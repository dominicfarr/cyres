A Resume to Job platform.
1 user only.
Take a resume in PDF or via MCP google drive, break it up into sections like, heading, summary, core skill, etc.
User provides a potential job via copy/paste or url.
Based on the Job Decription (JD) details, a new versioned resume will be simply, quickly, tailored to the JD. The sections will be checked one at a time.
Each check can be keep, select previous content, enter new content, replacing what was there, used in the new PDF, and stored for later.
Each section item collection will have tags for quick find
A new resume will be available in pdf.
The plaform will then generate 3 smoke questions an interview might focus around given the JD.
When the user is ready, the questions are given via speech, and the user must respond via voice only, not typing.
Depending on the depth and quality of the responses a score indicator will be determined.
The Q&A score indicator and User's fully history can provide a final match score.
Full history can include experiences and stiuations from previous roles. Honest—to always stay private and out of resumes—reasons behind events to help avoid bad matches.
